# Omar Rezk — Data & BI Portfolio

Live site: [https://omarrez2.github.io](https://omarrez2.github.io)

A multi-page, responsive portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and shadcn/ui.

## Project structure

The full folder guide, including where new files belong, is in
[docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md). In short: `src/` holds
the application, `public/` holds published assets, `assets-src/` holds local,
git-ignored original images and certificate uploads, `tests/` and `scripts/`
hold maintained tooling, and `docs/` holds documentation and audit evidence.

Framework/tool configuration stays at the root: `package.json`,
`package-lock.json`, `next.config.ts`, `tsconfig.json`, `next-env.d.ts`,
`eslint.config.mjs`, `postcss.config.mjs`, `playwright.config.ts` and
`components.json`. Keep `AGENTS.md`, `CLAUDE.md` and `START-PORTFOLIO.cmd`
in their existing locations. Run npm commands from this root directory.

### Generated files and optional cleanup

Generated output is disposable after its servers and checks have stopped. The
cleanup record is in [docs/maintenance/cleanup-2026-10-10.md](docs/maintenance/cleanup-2026-10-10.md).
These paths remain ignored by Git:

| Location | Purpose / when cleanup is safe |
| --- | --- |
| `node_modules/` | Installed dependencies. Only remove for a deliberate reinstall with `npm ci`; it is needed to run checks/dev/build. |
| `.next/` | Next.js build/dev output. Rebuildable after stopping the dev/production server; `npm start` requires a suitable production build. |
| `out/` | Static export used by local browser tests and Pages artifacts. Rebuildable with `GITHUB_PAGES=true npm run build`; keep it while serving/testing the export. |
| `test-results/`, `playwright-report/` | Generated browser results, traces and HTML report. Safe to remove when tests/report viewers are stopped and evidence is no longer needed; a test run regenerates them. |
| `.next/cache/tsconfig.tsbuildinfo` | TypeScript incremental cache (`tsBuildInfoFile` in `tsconfig.json`); lives inside `.next/` and is regenerated by type checking. |
| `next-env.d.ts` | Generated Next.js declarations; retained because TypeScript includes this file. |

Do not treat `docs/audit/audit-evidence/` as disposable build output: it contains
retained historical evidence. Likewise, `.tools/` and `assets-src/` are local
resources, not generated caches, and should not be bulk-cleaned.

Older portrait variants (`public/images/omar-hero.webp`, `omar-profile.webp`)
and starter SVG assets are retained for owner review; no active source reference
was found in the organization scan, but that does not prove they can be deleted
(for example, an external link may still use a public URL). No website assets,
content, routes, dependency versions or deployment settings changed.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

On the prepared Windows copy, you can also double-click `START-PORTFOLIO.cmd`; the included portable Node runtime will start the production site and open it in your browser.

After cleaning `.next`, build the local production version before using that
launcher. In PowerShell (Node 22 must be on PATH):

```powershell
Remove-Item Env:GITHUB_PAGES -ErrorAction SilentlyContinue
npm.cmd run build
```

To regenerate the static export for local browser tests instead:

```powershell
$env:GITHUB_PAGES = 'true'
npm.cmd run build
npm.cmd test
```

## Production

```bash
npm run build
npm start
```

## GitHub Pages

Every push to the `main` branch builds the static Next.js export and deploys it through GitHub Actions.

## Release checks

Use Node 22 and `npm ci`. Build with `GITHUB_PAGES=true` and the configured
`NEXT_PUBLIC_GA_MEASUREMENT_ID` (analytics remains off until visitor consent).
Then run `npm run lint`, `npm run typecheck`, `npx playwright install chromium`,
and `npm test`. The test server serves only the generated `out` directory on
127.0.0.1:4173. No real contact messages or analytics events are sent by tests.
On Windows use `npm.cmd` if PowerShell blocks npm.ps1. Optionally set
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` to an installed Chrome executable.

`TEST_BASE_URL=https://omarrez2.github.io` runs the same browser suite against
the deployed site. Generated reports/screenshots live in ignored
`playwright-report` and `test-results`; CI uploads them as an artifact.
See [the audit report](docs/audit/AUDIT_REPORT.md) for repair status and
[the baseline audit](docs/audit/AUDIT_BASELINE.md) for the original investigation.
[Audit evidence](docs/audit/audit-evidence/) retains baseline and release evidence.
